# Задача: Шифр Цезаря

## Навыки

- функции;
- строки;
- циклы;
- ветвления.

## Контекст

В некоторых задачах по информационной безопасности и обработке текстов используется простой, но показательный алгоритм — шифр Цезаря.

Это классический метод подстановки, в котором каждая буква заменяется другой с фиксированным смещением по алфавиту.

## Условие

Напишите функцию:

```python
caesar_cipher(data: str, key: int) -> str
```

Функция принимает:

- `data` — исходную строку;
- `key` — целое число, смещение по алфавиту.

Результат — новая строка, в которой каждая буква заменена на соответствующую букву со сдвигом на `key` позиций.

Все символы, которые не являются буквами, должны остаться без изменений.

Для алфавита используется:

```python
from string import ascii_letters as alpha
```
## Примеры

```python
caesar_cipher("Doggy", 5)
# "ItllD"

caesar_cipher("Python is the BEST!", 20)
# "jSNBIH CM NBy VYmn!"
```
